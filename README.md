# Rose Float Animation Simulation

Gilderfluke Simulation
Updated version made by @KLee-2524: https://github.com/KLee-2524/CPRF_JavaGilderTermSim

## Description

This program is intended to simulate Gilderfluke systems software.  Its a simple program to allow users to practice using the software and keyboard shortcuts without needing access to the animation box and float itself.

## Installation

1. This project is best when used with `pipenv`.  Step one should be installing this package on your local system.
2. Next, make sure Python is installed.  This project was created using Python 3.12 so its proabably best to use that one.
3. After installing `pipenv` and Python, use a terminal or command prompt to navigate to the folder where you cloned the repository.
4. Run `mkdir .venv` to create a new folder that will contain your virtual environment.
5. Run `pipenv sync` to install packages from the lock file.
6. Run `pipenv shell` to start using the virtual environment.
7. Now, you can run `python python.py` to start the simulation.
8. At any point, if you wish to close the simulation, you can press CTRL+C to break out of it.
